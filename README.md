<h1>Step 1: Create a GitHub Repository</h1>
<p>Log in to GitHub, click <strong>New Repository</strong>, enter a repository name, choose Public or Private, and click <strong>Create Repository</strong>.</p>

<h1>Step 2: Create a Local Folder</h1>
<p>Create a folder where you want to store your projects.</p>
<code>mkdir github-projects</code><br>  
<code>cd github-projects</code>
<code>ls</code>

<h1>Step 3: Clone the Repository</h1>
<p>Copy the repository URL from GitHub and run:</p>
<code>git clone https://github.com/your-username/your-repo-name.git</code>
<code>touch filename.html</code>

<h1>Step 4: Open the Repository</h1>
<p>Navigate into the cloned repository folder.</p>
<code>cd your-repo-name</code>

<h1>Step 5: Add Project Files</h1>
<p>Create or copy your files into the repository folder.</p>

<h1>Step 6: Save Changes with Git</h1>
<code>git add .</code><br>
or 
<code>git add filename.html</code>
<br>
<code>git commit -m "Initial commit"</code>

<h1>Step 7: Upload to GitHub</h1>
<code>git push origin main</code>

<p>
    Refresh your GitHub repository page to verify that your files have been uploaded successfully.
</p>
